## Gate 0 — Art Direction Statement

**Positioning:** Vanprastha is not a hotel-booking utility. It is the quiet luxury of the
Garhwal Himalayas — stone, river, pine, ritual. The site must feel like a private
resort's welcome desk, not an OTA search bar.

**Audience:** Affluent leisure travelers (35–60) seeking calm mountain stays in Uttarakhand;
couples + small families; decision time measured in hours, not minutes.

**Message (5 seconds):** "This is a place, not a product."

**Voice:** still · deliberate · warm. One noun the brand owns: **stillness**.

**Do-nots:** no stock AI navy+orange corporate palette; no centered hero with generic
photo + gradient stack; no 3-identical-card rows; no bouncing motion; no OTA-ish
bordered-form utility look on the first screen.

**Reference seeds (godly.website/recent.design, 2026-08-19):**
- `autumn-pricing-homepage` — warm seasonal palette discipline (proof: warmth alone sells).
- `becoming-editorial-project` — editorial type-led layout (proof: type can be the entire hero).
- `playground-001-editorial-prints` — print-grid rhythm, restraint, negative space.
- `tactile-webgl-shader-ui` — tactility as a differentiator (materials > gradients).

**Palette direction:** ivory/warm stone neutrals (#F7F4EE family), deep **pine green**
as primary hue (replaces corporate navy), **brass/aged-bronze** accent (replaces
AI-orange #F97316), charcoal ink for text. No pure-white surfaces; no #F97316 anywhere.

**Type direction:** Cormorant Garamond stays as the single display voice — used BIG,
light (400/500), sentence case, editorial-left alignment on the hero. Inter stays
for UI. **Remove Poppins** (third font, no role, perf + coherence cost).

**Motion feeling:** slow, damped, weighty reveals (600–900ms ease-out); parallax on
the hero image only; everything else still. Nothing bounces.

**One risk taken:** hero becomes type-led with the booking utility demoted below the
fold — conversion is protected by a persistent slim availability bar in the header/hero
foot instead of the floating OTA card.

## Critique — Current Design Language

| # | Finding | Severity |
|---|---------|----------|
| 1 | **`--accent: #F97316` (Tailwind orange-500) — the #1 AI-template tell.** Used for focus rings, selection, active nav underline, hero-glow radial, badge tint. Reads "generated by AI", kills luxury instantly. | HIGH |
| 2 | **`--primary: #234E70` corporate navy** — generic "trust" blue. No vernacular connection to the Himalayas. | HIGH |
| 3 | **Hero: centered text + full-bleed photo + linear gradient + pill badge + `bg-hero-glow` orange radial** = stock template composition. The "—" dash in the H1 and sentence case is right instinct, but centered-everything + orange = generic. | HIGH |
| 4 | **Floating booking card** (`-mt-20`, `rounded-[32px]`, `shadow-2xl`, `bg-white/95`) over the hero: competent utility, wrong brand posture for "stillness". Also competes with the two hero CTAs for hierarchy; the card wins, which demotes the brand story to an OTA. | MED-HIGH |
| 5 | **3 fonts loaded (Cormorant + Inter + Poppins)** via next/font/google; `--font-accent` usage is spotty. Perf + coherence cost with no payoff. | MED |
| 6 | **Dense home composition**: 9 sections after hero (WhyChoose → FeaturedRooms → Amenities → Experiences → QuoteBanner → Quote → Offers → Gallery → Testimonials). Luxury = fewer sections, more air; section paddings use default rhythm, not 96/120px breathing. | MED |
| 7 | **`line-height: 1.05` on all headings with `font-semibold` defaults** — Cormorant wants light weights + looser leading at scale; semibold Cormorant at 48px+ looks clunky. | MED |
| 8 | Pure-white surfaces (`--surface: #FFFFFF`) next to ivory `#FAFAF8` — no material warmth; slate borders (`border-slate-200`) everywhere = Tailwind default furniture look. | MED |
| 9 | Featured rooms: 3 identical cards in a row — the banned "9-cards" pattern parent. | MED |
| 10 | Buttons `rounded-full` pills + shadow-soft: fine, but secondary outline buttons on dark hero need checked contrast (bg gradient white 0.12 over photo). | LOW |

## Build Roadmap (execute in order; every phase = build → Edge screenshot → vision-verify → critique rubric ≥ 13/16 → iterate)

**P0 — Design tokens (foundation, lowest risk, single PR):**
- Swap palette: `--primary` navy #234E70 → pine #1E3A2D (or #234B38), `--accent` #F97316 → brass #A87A3B/#B08D57, background #FAFAF8 → #F7F4EE, surface → #FDFBF7, text → #2A2A28 (warm ink), border → warm alpha (rgba(42,42,40,0.14)), success → moss #4A6B4A.
- Kill `bg-hero-glow` orange radial; focus ring + selection follow brass (rgba alpha).
- Typography: drop Poppins import + `--font-accent`; headings light-weight (400/500), `line-height 1.15` at scale; kicker style = 11–12px uppercase tracking 0.3em brass.
- Gate: screenshot home/rooms/book before/after; vision-verify no orange pixels remain; page weight diff (one less font = win).

**P1 — Hero rebuild (editorial, type-led):**
- Left-aligned composition: small-caps kicker → Cormorant 500 at clamp(3.5rem, 8vw, 6.5rem) statement → one quiet sentence → single primary CTA "Reserve a stay" + text link "Explore rooms".
- Photo: keep full-bleed but strengthen lower-left vignette for type; slow parallax (framer scroll, 15–25% translate, damped).
- Booking card: demote to slim availability bar pinned at hero foot (date/date/guests/button, `bg-white/85 backdrop-blur`, max-w ~720px, rounded-xl, subtle border) — no giant shadow-2xl raft.
- Motion: single 900ms ease-out reveal for type; image fades 1.2s. No bounce, no stagger spam.

**P2 — Rooms elevation:**
- List: asymmetric editorial bento — first card 2-col span image-led; remaining cards alternate offset; price becomes subtext ("from ₹X/night" small caps), not the loudest element; hover = slow image scale 1.03 + brass underline.
- Detail: gallery gets index numerals "01 / 04" + prev/next hairline UI; booking sidebar calms (remove default shadow-2xl → hairline border + ivory surface).

**P3 — Book flow + post-payment:**
- VERIFY auth-interrupt state preservation (register/login redirect back to /book state).
- VERIFY post-payment screen; if absent: build confirmation page (booking ref, amount, next steps) — mirrors webhook CONFIRMED state; profile gets "View details".
- Unify form fields: underline-style inputs (hairline bottom border, focus = brass) instead of bordered boxes on the booking surfaces.

**P4 — Auth/profile:** token consistency only (P0 palette lands automatically).

**P5 — Admin:** nothing beyond P0 tokens. Utility = calm utility.
